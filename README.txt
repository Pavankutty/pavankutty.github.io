PAVAN PORTFOLIO — QUICK PUBLISH GUIDE

1. Extract the ZIP file.
2. Open index.html in a browser to preview the portfolio.
3. To publish free using GitHub Pages:
   a. Sign in to https://github.com/Pavankutty
   b. Create a new public repository named: pavankutty.github.io
   c. Upload index.html to the repository root and commit the change.
   d. Open repository Settings > Pages and ensure deployment from the main branch / root is selected.
   e. Wait for GitHub Pages to publish. Your site address will be:
      https://pavankutty.github.io/
4. Open the published URL in an incognito/private browser window to confirm it works before adding it to applications.

Before publishing, verify every detail and replace/remove any project descriptions that don't accurately reflect your contribution. Add individual project repository links when available. No live project links are claimed in this template.
